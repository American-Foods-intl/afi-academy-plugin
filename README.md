# AFI Academy plugin for Claude Code

The `afi-academy` plugin lets American Foods course authors (HR, team leaders) create and update
AFI Academy training courses by talking to Claude: type `/afi-course`.

It holds no keys or company data. To use it, you need your own personal key from the AFI Academy
(**Me → Connect Claude**).

## Install

In Claude Code:

```
/plugin marketplace add https://github.com/American-Foods-intl/afi-academy-plugin.git
/plugin install afi-academy@afi-academy-plugin
```

Or ask Claude: "Install the AFI Academy plugin from https://github.com/American-Foods-intl/afi-academy-plugin.git".

Then follow [plugins/afi-academy/README.md](plugins/afi-academy/README.md) to connect your Academy key.
